========================================================================
 다듬 스튜디오 — 맞춤법 검사 / 국어사전 API 연동 안내
========================================================================

■ 무엇을 연동했나요?  (2026-07-27 갱신)

  1) 국어사전 검색         → 국립국어원 표준국어대사전 "공식" 오픈 API  ✅
     https://stdict.korean.go.kr/api/search.do
     - 무료, 공식, 이용약관상 문제 없음
     - .env 파일의 STDICT_KEY 에 인증키를 넣어야 동작합니다
     - 이전에는 다음(Daum) 사전 페이지를 스크레이핑했으나,
       타사 콘텐츠 무단 수집은 이용약관 및 구글 애드센스 정책 위반이라
       공식 API로 전면 교체했습니다.

  2) 맞춤법·띄어쓰기 검사  → 다음(Daum) 맞춤법 검사기  ⚠️ 교체 필요
     https://alldic.daum.net/grammar_checker.do
     - 여전히 스크레이핑 방식이며, 실제로 이미 403(차단) 응답이
       확인되었습니다. 현재는 대부분 브라우저 내장 규칙 엔진
       (js/checker-engine.js)으로 자동 대체되어 동작합니다.
     - 사이트를 공개 배포하고 광고를 붙일 계획이라면 반드시
       교체해야 합니다. 아래 "맞춤법 검사 엔진 교체" 항목 참고.

  브라우저는 외부 도메인을 직접 호출할 수 없어(CORS 차단) server.js라는
  작은 프록시 서버가 대신 요청을 보내고, 결과를 우리 화면에 맞는 JSON으로
  정리해서 돌려줍니다.


■ 왜 부산대 맞춤법 검사기를 안 썼나요?

  예전에 가장 널리 쓰이던 "부산대학교 맞춤법 검사기"
  (speller.cs.pusan.ac.kr)는 실제로 접속을 시도해보니 도메인 자체가
  존재하지 않았습니다(DNS 조회 실패). 서비스가 완전히 종료된 상태입니다.
  대신 현재 정상 동작 중인 다음(Daum) 맞춤법 검사기로 직접 요청을 보내
  응답을 확인한 뒤 연동했습니다.


■ 실행 방법

  0. 처음 한 번만: .env.example 파일을 복사해 ".env" 로 이름을 바꾸고
     STDICT_KEY= 뒤에 발급받은 인증키를 붙여넣으세요.
     (키 없이 실행하면 국어사전 기능만 비활성화되고 나머지는 동작합니다)

  1. Node.js가 설치되어 있어야 합니다 (이미 설치되어 있음: node -v로 확인)
  2. 프로젝트 폴더에서 터미널을 열고:

       node server.js
       (또는 npm start)

  3. 아래처럼 뜨면 정상 실행된 것입니다:

       다듬 스튜디오 서버 실행 중: http://localhost:3787

  4. 브라우저에서 http://localhost:3787 접속
     (index.html 파일을 더블클릭해서 직접 여는 방식은 이제 사용하지 마세요.
      그 경우 API 서버에 연결할 수 없어 자동으로 "로컬 규칙 검사"로만
      동작합니다. 화면 우측 상단의 상태 표시로 확인 가능합니다.
      🟢 정밀 API 검사 연결됨 / ⚪ 로컬 규칙 검사)

  server.js는 express 등 외부 패키지를 설치할 필요 없이 Node.js 내장
  기능만으로 동작하도록 만들어서, npm install 없이 바로 실행됩니다.


■ 한계 및 유의사항 (중요)

  - 이 방식은 다음(Daum) 웹페이지의 공식 API가 아니라, 실제 웹페이지가
    응답하는 HTML을 서버에서 대신 읽어와 필요한 부분만 추출(스크레이핑)
    하는 방식입니다. 다음 쪽에서 페이지 구조를 바꾸면 예고 없이 깨질 수
    있습니다.
  - 개인적/학습 목적의 소규모 사용에는 문제가 없지만, 트래픽이 많은
    서비스로 정식 배포할 계획이라면 상업적 이용약관 문제가 생길 수 있어
    권장하지 않습니다. 그 경우 아래의 "공식 API" 섹션을 참고하세요.
  - 과도하게 빠른 연속 요청(예: 매 타이핑마다)은 차단될 수 있어, 실시간
    모드에서도 입력이 멈춘 뒤 0.6초 후에만 검사 요청을 보내도록
    디바운스를 걸어두었습니다.
  - 서버가 요청 처리에 실패하면(네트워크 문제, 다음 서버 응답 지연 등)
    화면은 자동으로 내장 규칙 기반 로컬 엔진(js/checker-engine.js)으로
    전환되어 계속 사용할 수 있습니다.


■ 국어사전 인증키 발급 방법 (필수)

  1. https://stdict.korean.go.kr/openapi/openApiInfo.do 접속 후 회원가입
  2. "오픈 API 신청" → 인증키(API key) 발급 (무료, 즉시 발급)
  3. 프로젝트 폴더의 .env 파일에 붙여넣기:

       STDICT_KEY=여기에_발급받은_인증키

  4. 인증키는 절대 깃(GitHub)에 커밋하지 마세요.
     .env 는 이미 .gitignore 에 등록되어 있습니다.
     배포 플랫폼(Render/Vercel 등)에서는 대시보드의
     "Environment Variables" 메뉴에 같은 이름으로 등록하면 됩니다.


■ 맞춤법 검사 엔진 교체 (공개 배포 전 필수)

  국립국어원은 "맞춤법 검사" 자체는 공식 API로 제공하지 않습니다.
  현재의 Daum 스크레이핑은 이미 403 차단이 확인된 상태라, 아래 중
  하나로 교체해야 합니다.

    (a) 자체 규칙 엔진 고도화  — js/checker-engine.js 의 규칙을 늘리는 방식.
        비용 0원, 완전 합법, 다만 정확도에 한계.

    (b) LLM API 기반 교정      — Claude API 등으로 문장을 교정.
        정확도 최상, 문맥까지 이해. 사용량만큼 과금.

    (c) 상용 한국어 NLP API    — Bareun.ai, 네이버 클로바 등. 유료.

  어느 쪽을 택하든 server.js 의 checkChunkWithDaum() 함수 한 곳만
  바꾸면 됩니다. 서버가 {issues: [...]} 형태의 JSON을 동일하게
  반환하기만 하면 프런트엔드(app.js)는 수정할 필요가 없습니다.


■ 배포 시 반드시 설정할 환경변수

    STDICT_KEY      국어사전 인증키
    ALLOWED_ORIGIN  내 도메인 (예: https://dadeum.kr)
                    설정하지 않으면 누구나 내 서버를 무료 API 서버처럼
                    쓸 수 있어, 외부 서비스에서 IP가 차단될 수 있습니다.
    PORT            배포 플랫폼이 자동으로 넣어주므로 보통 설정 불필요
