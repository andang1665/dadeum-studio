사이트 소개

최종 수정일: 2026년 7월 27일

다듬 스튜디오(Dadeum Studio)는 한국어 문장의 맞춤법과 띄어쓰기를 점검하고, 글의 어조를 상황에 맞게 다듬을 수 있도록 돕는 무료 웹 도구입니다. '다듬다'라는 우리말에서 이름을 가져왔습니다.

왜 만들었나요

자기소개서를 쓰다가, 보고서를 제출하기 직전에, 논문 초록을 다듬으면서 "이게 맞나?" 싶은 순간이 누구에게나 있습니다. 기존 검사 도구들은 광고가 많거나, 회원가입을 요구하거나, 결과만 보여줄 뿐 왜 틀렸는지 알려주지 않는 경우가 많았습니다.

다듬 스튜디오는 세 가지에 집중했습니다.

  • 이유를 알려줍니다. 단순히 고쳐주는 데서 그치지 않고, 어떤 규칙에 따라 왜 그렇게 고쳐야 하는지 설명합니다.
  • 가입이 필요 없습니다. 페이지를 열고 문장을 붙여넣으면 그걸로 끝입니다.
  • 글을 저장하지 않습니다. 입력한 문장은 검사에 필요한 순간에만 처리되고 서버에 남지 않습니다.

주요 기능

  • 실시간 / 수동 검사 — 타이핑하면서 바로 확인하거나, 긴 글을 한 번에 점검할 수 있습니다.
  • 오류 유형 구분 — 맞춤법 오류, 띄어쓰기 오류, 어휘 선택 오류를 색으로 구분해 보여줍니다.
  • 어조 변환 — 격식체(합쇼체), 친근체(해요체), 보고서체(개조식)로 문장 끝맺음을 일괄 변환합니다.
  • 파일 업로드 — PDF, DOCX, TXT 파일의 본문을 자동으로 추출해 검사합니다.
  • 사용자 사전 — 고유명사나 신조어를 등록해 검사에서 제외할 수 있습니다.
  • 국어사전 검색 — 국립국어원 표준국어대사전에서 단어의 뜻을 바로 찾아봅니다.

사용한 데이터와 기술

  • 국어사전 — 국립국어원이 제공하는 표준국어대사전 오픈 API 공식 데이터를 사용합니다.
  • 맞춤법 검사 — 국립국어원 한글 맞춤법 규정을 기반으로 한 자체 검사 엔진이 브라우저에서 동작합니다.
  • 파일 텍스트 추출 — 오픈소스 라이브러리 PDF.js와 Mammoth.js를 사용하며, 파일은 사용자의 브라우저 안에서만 처리되고 서버로 업로드되지 않습니다.

한계와 주의사항

맞춤법 검사기는 문맥을 완벽하게 이해하지 못합니다. 문학적 표현, 고유명사, 전문 용어, 의도적인 구어체는 오류로 잘못 표시될 수 있습니다. 제안된 교정은 참고 자료로 활용하시고 최종 판단은 직접 해주시기 바랍니다.

문의

기능 제안, 오류 신고, 제휴 문의는 문의하기 페이지를 이용해 주세요. 사용자 의견을 반영해 계속 개선하고 있습니다.
